# MatrixHunter

通用内存矩阵发现与验证工具 —— 用「已知世界坐标 + 象限过滤」把候选矩阵地址逐步收敛到唯一正确解，并在透明叠加层上实时验证投影结果。

> **v2.0.0**：已用 **Rust + Tauri + React** 完全重写（旧版为 Python + PySide）。

## 功能

### 目标进程
- 进程列表（64 / 32 位标记、按名称或 PID 搜索）
- 双击附加，或用「拖拽选窗」拖到目标窗口上松开即自动附加
- **窗口信息面板**：窗口句柄、标题、类名、进程名、PID、进程位数、进程路径、窗口与客户区的位置尺寸、窗口样式与扩展样式（只读，可选中复制）

### 矩阵查找（核心）
- 候选地址每行一个，支持三种写法：
  - 绝对地址：`0x7FF6A1B2C3D0`、`14C3D0A0`
  - **模块 + 偏移**：`"Game-Win64-Shipping.exe"+B699A54`（引号可省略、模块名大小写不敏感、可省略扩展名）
- 数据类型：`float` / `double`
- 每个地址展开为 **8 种矩阵方案**：`4x4 / 3x4` × `v*M / M*v` × `+w / -w`（已去除布局与方向的等价冗余）
- **过滤**：读取矩阵 → 投影已知世界坐标 → 淘汰投影点不在目标象限的方案；全灭时自动回滚，支持撤销
- 读取失败的地址会被记录，连续两轮失败后自动淘汰，避免无效地址卡住过滤

### 方案结果
- 分页展示（每页 200 条），支持「存活 / 淘汰 / 全部」筛选与关键字搜索
- **实时预览**：一步完成「选中 + 开启实时追踪」，再次点击即停止
- **复制算法**：导出一套可直接编译使用的 C++ 代码（读矩阵、矩阵构建与运算、NDC → 客户区 → 屏幕坐标换算），只需填入世界坐标与窗口信息
- 复制地址、删除方案

### 骨骼编号
- 骨骼基址、数量、步长；矩阵地址与「解释方式」均取自当前选中方案（只读）
- **点位筛选方式**（二选一）：
  - **按显示序号**：白名单，支持 `1,3,5` 或 `1-3`，适合骨骼点很多时分段查看
  - **按连接关系**：只绘制连接关系里出现过的点，用于预览最终点位图
- **人体模板**：填入头 / 颈 / 胸 / 腰 / 四肢对应的骨骼序号，一键生成骨架连接关系，支持复制模板
- **绘制样式**：序号字号与颜色、连线粗细与颜色、关节大小 / 轮廓粗细 / 颜色（均支持 RGBA 透明度，字号与连线可单独开关隐藏）

### 叠加层
- 透明、置顶、鼠标穿透的独立窗口，自动跟随目标客户区
- 象限参照：十字线（颜色 / 宽度可调）+ 四个象限字母（透明度可调）
- 实时点、预览点（金色准星标记）、骨骼点与连线
- 左上角图例说明

### 其他
- 标题栏实时性能监测：本程序 CPU 占用（占整机百分比）、内存工作集及其占物理内存的比例
- 设置：主题（深色 / 浅色 / 跟随系统）、强调色、刷新频率、客户区尺寸覆盖
- 配置持久化：后端写入 `%APPDATA%\com.matrixhunter.app\settings.json`，界面偏好存于 WebView 本地存储

## 使用流程

1. **附加进程**：在「目标进程」里双击进程，或拖拽选窗到游戏窗口
2. **确定方案**：已知矩阵地址时，把它填进「矩阵查找」→「枚举矩阵」→「过滤」（用已知世界坐标 + 象限筛掉无效方案）→ 在右侧选中唯一存活方案
3. **验证**：点「实时预览」，转动镜头看投影点是否跟着目标走
4. **骨骼**：切到「骨骼编号」，填入骨骼基址与数量，开启「启用」，按需配置显示序号 / 连接关系与人体模板

> 说明：同一个地址可能是 8 种方案之一，只有在「矩阵查找」里枚举 + 过滤确定方案后，骨骼与实时的结果才准确。

## 构建

前置：Node.js 18+、Rust 1.77+、Windows（需 WebView2 运行时）

```bash
npm install
npm run tauri:dev      # 开发调试
npm run tauri:build    # 编译并打包
```

产物：

- `src-tauri/target/release/matrixhunter.exe`
- `src-tauri/target/release/bundle/nsis/MatrixHunter_<version>_x64-setup.exe`

## 技术栈

| 层 | 技术 |
| --- | --- |
| 前端 | React 18 + TypeScript + Vite |
| 后端 | Rust（Tauri 2）+ windows-sys（Win32 原始 FFI） |
| 打包 | Tauri NSIS |

## 目录结构

```
src/                  前端（React）
  components/         界面组件（叠加层、取色器、结果表、窗口信息面板等）
  hooks/              状态与外观
  lib/                API 封装、解析、算法导出
src-tauri/            后端（Rust）
  src/win32.rs        Win32 封装（进程、内存、窗口、性能）
  src/engine.rs       矩阵枚举 / 投影 / 过滤
  src/runtime.rs      窗口跟随 / 实时点 / 骨骼线程
  src/commands.rs     Tauri 命令
```
