# MatrixHunter

MatrixHunter 是一款通用的内存矩阵发现与验证工具。

通过“世界坐标 → 屏幕象限”的多轮过滤，从一批疑似矩阵地址中自动筛选出正确的“内存地址 + 矩阵方案”，并支持透明置顶叠加层（Overlay）实时绘制验证。

---

## 核心特性

- **零矩阵知识假设**：无需预先理解行主序/列主序、前乘/后乘等概念，软件自动枚举 12 种矩阵解释方案组合。
- **通用性**：不绑定特定游戏，支持 32/64 位进程读取，支持 `float` / `double` 浮点精度。
- **象限过滤算法**：用户只需视觉判断静态目标当前位于屏幕的哪个象限（左上、右上、左下、右下），多轮淘汰不符方案。
- **容差与防误杀**：智能识别接近屏幕十字中心线的模糊边界点，自动跳过而非误杀正确方案。
- **透明置顶叠加层**：采用 Windows 穿透透明层精确贴合目标客户区，支持白色十字参考线、黄色临时预览点、绿色实时跟踪圆圈。
- **窗口吸附与选择**：内置 🎯 准星拖拽捕获游戏窗口功能，自动解析进程与窗口信息。

## 快速开始

### 方式一：直接运行 Releases 编译版本（推荐）

从 [Releases](https://github.com/meesst/MatrixHunter/releases) 下载最新发布的 `MatrixHunter.exe` 或压缩包解压后直接双击运行，无需配置 Python 环境。

### 方式二：从源码运行

要求：Python 3.10+，Windows 10 / 11 64位。

```bash
# 克隆仓库
git clone https://github.com/meesst/MatrixHunter.git
cd MatrixHunter

# 安装依赖
pip install -r requirements.txt

# 启动程序
python main.py
```

### 打包为独立可执行文件

项目自带 PyInstaller 构建规范：

```bash
pyinstaller MatrixHunter.spec
```

打包产物位于 `dist/MatrixHunter.exe`。

## 使用流程

1. **附加游戏进程**：
   - 在顶部“进程”下拉列表中选择目标游戏进程，点击“附加”；
   - 或点击旁边的 🎯 按钮，鼠标移动并点击目标游戏窗口进行识别和附加。
2. **设置矩阵数据类型**：
   - 选择内存数据精度（`float` 32位 或 `double` 64位）。
3. **输入疑似地址**：
   - 在左侧“地址列表”粘贴一组疑似矩阵地址（一行一个，支持 `0x` 前缀）。
4. **枚举候选方案**：
   - 点击“枚举候选方案”，系统自动为每个地址生成 12 种变换方案。
5. **象限过滤**：
   - 在右侧输入游戏内某静态物体的世界坐标 `(X, Y, Z)`；
   - 转动游戏视角，观察该物体处于目标窗口的哪个象限；
   - 点击对应象限按钮（左上 TL / 右上 TR / 左下 BL / 右下 BR）进行淘汰；
   - 转动视角重复过滤 2~4 轮，直到方案收敛至唯一。
6. **实时绘制验证**：
   - 在结果列表中选中收敛方案，点击“选用”；
   - 勾选“实时绘制”，在叠加层观察绿色标记点是否稳定锁定在目标物体上。

## 快捷键说明

| 快捷键 | 功能 |
|---|---|
| `F8` | 显示 / 隐藏屏幕叠加层 |
| `F9` | 切换实时绘制状态 |
| `ESC` | 取消实时绘制 |

---

## 适用范围与限制

- **适用**：
  - 目标进程具备内存读取权限；
  - 矩阵为连续存储的单矩阵（如 ViewProjection 矩阵或等价形式）。
- **限制**：
  - 不支持 View / Projection 分离存储且需要二次相乘的场景；
  - 不修改目标进程内存，仅执行读取操作。
